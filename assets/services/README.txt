ONLINE SERVICES PRODUCTS

Create one folder per product:
assets/services/product-001/

Inside:
- info.json
- product.jpg (or png/webp)

Example info.json:
{
  "name": "Example Product",
  "price": "25",
  "currency": "€",
  "description": "Short product description.",
  "category": "Digital",
  "badge": "NEW",
  "available": true,
  "image": "product.jpg",
  "order_message": "Hello DIBOXE LEGIT, I want to order Example Product."
}

The Order button opens WhatsApp for +385976853088.
